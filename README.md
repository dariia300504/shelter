## Про проєкт

Система допомагає потенційному власнику обрати тварину з притулку. Користувач заповнює анкету
(житло, досвід, наявність дітей та інших тварин, бажаний вид, вік, рівень активності, вільний час),
а система:

- відсіює тварин, які йому не підходять (несумісність з дітьми чи іншими тваринами,
  велика тварина для житла без умов, тварина вже заброньована);
- для решти рахує бал сумісності як зважену суму оцінок за шістьма критеріями;
- додає невеликий бонус тваринам, евакуйованим із зон бойових дій;
- повертає список найкращих варіантів із коротким поясненням, чому саме ця тварина.

Ваги критеріїв адміністратор може змінювати без втручання в код.

## Що потрібно для запуску

- Python 3.12 (підійде й 3.10 або новіший);
- PyCharm, VS Code або будь-який інший редактор коду;
- PostgreSQL 16 — тільки якщо потрібно запускати API з базою даних;
- для перевірки алгоритму база даних не потрібна;
- для перегляду інтерфейсу достатньо браузера.

## Як переглянути інтерфейс

Відкрити посилання https://dariia300504.github.io/shelter/ або відкрити файл `index.html` у браузері.
Можна пройти весь сценарій: заповнити анкету, переглянути рекомендовані тварини з поясненнями,
записатися на зустріч і оформити усиновлення.

## Як відкрити проєкт

1. Завантажити код: на сторінці репозиторію натиснути **Code → Download ZIP** і розпакувати архів
   або виконати `git clone https://github.com/dariia300504/shelter.git`.
2. Відкрити папку проєкту в редакторі (у PyCharm: **File → Open**).
3. У терміналі редактора створити віртуальне середовище і встановити бібліотеки:

   ```
   python -m venv .venv
   .venv\Scripts\activate        (Windows)
   source .venv/bin/activate     (macOS / Linux)
   pip install -r requirements.txt
   ```

## Перевірка алгоритму на контрольному прикладі

```
python tests/test_control.py
```

Скрипт бере профіль користувача й шість тварин із `data/control_input.json` і запускає підбір.
Має вийти такий результат:

| Місце | Тварина | Бал |
|---|---|---|
| 1 | Барсик | 0,92 |
| 2 | Луна | 0,86 |
| 3 | Річі | 0,78 |
| 4 | Боня | 0,61 |

Рекс і Джек у список не потрапляють: Рекс — великий пес, а в користувача квартира без умов,
Джек уже заброньований. Барсик на першому місці завдяки бонусу пріоритету, бо він евакуйований.
У кінці скрипт пише «OK: результат збігається з додатком Д».

## Запуск API разом із базою даних

1. Створити в PostgreSQL користувача `app` з паролем `app` і базу `pets`, після чого виконати скрипт бази:

   ```
   psql -U app -d pets -f db/schema.sql
   ```

2. Запустити сервер:

   ```
   cd app
   uvicorn main:app --reload
   ```

   Якщо база має інші параметри, перед запуском потрібно задати змінну `DATABASE_URL`,
   наприклад `postgresql://користувач:пароль@localhost/pets`.

3. Відкрити в браузері http://127.0.0.1:8000/docs. На цій сторінці можна виконати всі запити:
   - `POST /questionnaire` — зберегти анкету;
   - `GET /recommendations` — отримати рекомендації за номером анкети;
   - `POST /appointments` — забронювати тварину для зустрічі;
   - `PUT /admin/criteria` — змінити ваги критеріїв (сума ваг має дорівнювати 1).

## Що реалізовано, а що ні

Це прототип: у ньому працює основний цикл підбору від анкети до списку рекомендацій із поясненнями,
бронювання тварини та зміна ваг.

Реєстрація і вхід користувачів, ролі, редагування карток тварин, оформлення усиновлення
й повернення, журнал змін ваг і статистика описані в роботі як проєктні рішення,
але в коді прототипу їх поки немає.

Інтерфейс за посиланням є демонстраційним: він працює на умовних даних, не підключений
до API-сервера і зберігає введене лише до перезавантаження сторінки.

Дані контрольного прикладу умовні: це не реальні тварини і не реальні користувачі.
