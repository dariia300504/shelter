# Дім для друга

Прототип системи підтримки прийняття рішень персоналізованого підбору домашньої тварини із притулку (магістерська робота, НУ «Львівська політехніка», група САСМ-21, Ільчук Д. С.).

- `index.html` — вебпрототип (анкета, рекомендації, запис на зустріч, усиновлення, панель адміністратора).
- `backend/schema.sql` — структура бази даних PostgreSQL 16.
- `backend/matching.py` — модуль підбору (жорсткі критерії, зважена сума, бонус пріоритету, пояснення).
- `backend/api.py` — API-сервер на FastAPI.
